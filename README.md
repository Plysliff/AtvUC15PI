## Objetivo do Software:
Sistema básico para estudos, baseado em RPGs, com as funções de guardar personagens criados por um usuário, e seus respectivos itens.

## Tecnologias Aplicadas:
- **Linguagem:** Java (JDK)
- **Interface Gráfica:** Java Swing
- **Banco de Dados:** MySQL
